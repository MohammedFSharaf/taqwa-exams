# اختبارات مركز التقوى لتعليم وتحفيظ القرآن الكريم

- `app/` تطبيق الأندرويد (Flutter) — يعمل بدون إنترنت ويرفع الاختبارات تلقائياً.
- `docs/index.html` لوحة الإدارة (تُنشر على GitHub Pages).
- `firestore.rules` قواعد حماية قاعدة البيانات (تُلصق في Firebase ← Firestore ← Rules).
- `.github/workflows/build-apk.yml` يبني ملف APK تلقائياً على GitHub (Actions ← آخر تشغيل ← taqwa-exams-apk).

قواعد العلامات: 5 أسئلة × 15، الخطأ −1، التنبيه −½، أحكام التجويد 20، الأداء 5، النجاح من 85.
يُغلق الاختبار (راسب) إذا وصل الخصم في سؤال واحد إلى 9 علامات.
